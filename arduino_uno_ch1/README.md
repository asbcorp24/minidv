# Arduino Uno для CH1 и DM556

Отдельный скетч для Arduino Uno R3 на ATmega328P с логикой 5 В. ESP32 сохраняет свою прошивку и все функции CH1, CH2 и CH3. Для работы с Uno подключите входы одного DM556 только к Uno.

## Подключение

| Источник | Назначение |
| --- | --- |
| Сигнал S канала CH1 приёмника MC8RE-V2 | Uno D2 |
| GND приёмника | Uno GND |
| Uno D8 | DM556 PUL+ |
| Uno D9 | DM556 DIR+ |
| Uno D10 | DM556 ENA+ |
| Uno GND | DM556 PUL−, DIR−, ENA− |
| Резистор 10 кОм между Uno D8 и GND | Удержание STEP в нуле во время сброса |
| Силовой источник +24 В | DM556 +V |
| Минус силового источника | DM556 GND |
| Первая обмотка двигателя | DM556 A+ и A− |
| Вторая обмотка двигателя | DM556 B+ и B− |

Uno питайте от USB. Приёмник MC8RE-V2 питается от предусмотренного для него источника 4,5–6 В, обычно 5 В. Объедините сигнальные земли. При нескольких USB-источниках объединяйте земли, питание 5 В каждого устройства оставляйте от своего источника.

Для этой схемы выходы Uno подключаются к DM556 напрямую. На входах DM556 должен быть выбран уровень 5 В, если на конкретной версии есть переключатель 5/24 В. Код использует ENA HIGH для отключения и ENA LOW для разрешения. Проверьте полярность ENA по инструкции своего экземпляра. Силовые выводы и обмотки подключайте при выключенном питании.

Выходы STEP/DIR/ENA Uno и ESP32 нельзя соединять друг с другом. ESP32 продолжает выполнять прежний код, но к этому DM556 его выходы не подключаются. Сигнал CH1 приёмника можно оставить на ESP32 через прежнее согласование уровней и параллельно подать на D2 Uno.

## Управление

| Длительность импульса CH1 | Команда |
| --- | --- |
| Ниже 1000 мкс | Стоп |
| 1000–1399 мкс | Одно направление |
| 1400–1600 мкс | Стоп |
| 1601–2000 мкс | Противоположное направление |
| Выше 2000 мкс | Стоп |
| Нет импульсов более 200 мс | Стоп |

Проверка диапазона выполняется до определения направления. Нулевое и недопустимое значение не превращается в команду 1000 мкс. Нейтраль и недопустимый принятый импульс сразу прекращают STEP. При пропадании импульсов срабатывает тайм-аут 200 мс. При восстановлении допустимой команды движение возобновляется после задержки включения драйвера 300 мс.

Максимальная частота фиксирована на 60 импульсах STEP/с, разгон — 30 импульсов/с². Реверс проходит через нулевую скорость. STEP HIGH длится 5 мкс, DIR устанавливается за 10 мкс до STEP. Параметры MAX_STEP_SPEED и STEP_ACCEL находятся в начале скетча.

По таблице на присланном DM556 для 400 импульсов/оборот задайте SW5=OFF, SW6=ON, SW7=ON, SW8=ON. При 60 импульсах/с это 9 об/мин. SW1–SW3 устанавливают ток по паспорту двигателя и таблице Peak на драйвере.

Если приёмник после выключения пульта продолжает выдавать допустимую команду движения, скетч воспринимает её как обычную команду. Настройте Failsafe приёмника на нейтраль около 1500 мкс или прекращение импульсов.

## Загрузка через PlatformIO

1. Подключите Uno по USB. Для первой загрузки отключите силовое питание DM556.
2. В VS Code выберите File → Open Folder и откройте папку arduino_uno_ch1 с её собственным platformio.ini.
3. Выберите окружение uno, выполните Build, затем Upload.
4. Откройте Serial Monitor на 115200 бод.
5. Если порт не определился автоматически, добавьте upload_port = COMx и monitor_port = COMx в секцию [env:uno], подставив свой порт.

Через терминал из корня репозитория выполните:

```powershell
pio run -d arduino_uno_ch1 -e uno
pio run -d arduino_uno_ch1 -e uno -t upload
pio device monitor -p COMx -b 115200
```

Файл src/main.cpp подключает тот же скетч arduino_uno_ch1.ino. Настройки порогов, скорости и пинов меняются в одном месте.

## Загрузка через Arduino IDE и проверка

1. Откройте arduino_uno_ch1.ino в Arduino IDE.
2. Выберите плату Arduino Uno и порт подключённой Uno.
3. Загрузите скетч. Программирование ESP32 выполняется отдельно.
4. Откройте Serial Monitor на 115200 бод.
5. Сначала отключите силовое питание DM556. Проверьте состояния OK, OUT_OF_RANGE, LOST, значения command и speed.
6. После настройки тока и микрошагов проверьте свободное вращение в обе стороны и остановку.
