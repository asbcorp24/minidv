# ESP32 DevKit с тремя RC каналами

## Принцип работы

- **CH1 → DM556 / NEMA17**: непрерывное вращение. 1000–1399 мкс — одно направление, 1400–1600 мкс — стоп, 1601–2000 мкс — противоположное направление. Значения ниже 1000 и выше 2000 дают стоп без ограничения к краю диапазона. Пороговые значения 1400 и 1600 включены в зону стопа. Скорость фиксированная, максимум 60 импульсов STEP/с, разгон 30 импульсов/с². Реверс проходит через нулевую скорость. Нейтраль, недопустимая ширина принятого импульса и потеря сигнала сразу прекращают выдачу шагов.
- После разрешения DM556 выдерживается 300 мс до первого шага. При отсутствии допустимых RC-импульсов CH1 отключается через 200 мс. При появлении команды вращение может начаться без предварительного возврата в нейтраль.
- **CH2 → HW-039 / актуатор 12 В, два провода**: 1000–1449 мкс одна сторона; 1450–1550 стоп; 1551–2000 другая сторона. Полный ШИМ достигается при 1000 и 2000 мкс. Принятые импульсы ниже 1000 ограничиваются до 1000, выше 2000 — до 2000. Импульсы вне диапазона захвата 800–2500 мкс отвергаются и не обновляют таймер наличия сигнала. Плавный разгон/реверс. Непрерывная команда движения прекращается через **10 секунд**, сброс таймера только после возврата в нейтраль. После потери радиосигнала требуется нейтраль для повторного включения.
- **CH3 → DAC1 GPIO25 + реле GPIO13**: `<=1440` — реле включено и ЦАП от 0 до максимума к 900 мкс; `1441..1549` — 0 В; `>=1550` — реле выключено и ЦАП возрастает до максимума при 2400 мкс. При реверсе сначала плавное снижение ЦАП до нуля, пауза 150 мс для переключения реле, затем плавный рост.

## Пины ESP32

| Функция | ESP32 | Подключить |
| --- | --- | --- |
| CH1 RC PWM | GPIO27 | сигнал приёмника CH1 |
| CH2 RC PWM | GPIO34 | сигнал приёмника CH2 |
| CH3 RC PWM | GPIO35 | сигнал приёмника CH3 |
| DM556 PUL / DIR / ENA | GPIO16 / GPIO17 / GPIO21 | через неинвертирующий интерфейс 3,3 → 5 В |
| HW-039 RPWM / LPWM | GPIO32 / GPIO33 | RPWM / LPWM |
| HW-039 R_EN / L_EN | GPIO23 / GPIO22 | R_EN / L_EN |
| HW-039 питание логики | отдельные 5 В | VCC и GND (общая земля) |
| ЦАП | GPIO25 | аналоговый высокоомный вход, **не питание нагрузки** |
| Реле | GPIO13 | управляющий вход модуля реле, **не катушка напрямую** |

Актуатор подключается двумя проводами к M+/M− HW-039. Силовое питание актуатора 12 В подключается к B+/B− HW-039.

Сигнал RC с уровнем 5 В **нельзя** подавать прямо на ESP32: используйте делитель 1 кОм от выхода приёмника к GPIO и 2 кОм от GPIO к GND на каждом RC-канале, если выход приёмника 5 В. GPIO34/35 не имеют внутренних подтяжек. **Общая земля обязательна.** Питать ESP32 от USB, логику HW-039 — от 5 В. Для некоторых релейных модулей нужен транзисторный ключ или согласование уровней. Поставьте физические концевики и защиту тока актуатора: программный таймер не защищает от упора раньше 10 секунд.

## Подключение DM556

Код рассчитан на режим PUL/DIR и неинвертирующий интерфейс 3,3 → 5 В с выходным током не менее 16 мА на канал. Прямое подключение GPIO ESP32 к входам DM556 требует проверки параметров конкретной модели.

| Контакт DM556 | Подключение |
| --- | --- |
| PUL+ | Выход интерфейса 5 В от GPIO16 |
| DIR+ | Выход интерфейса 5 В от GPIO17 |
| ENA+ | Выход интерфейса 5 В от GPIO21 |
| PUL−, DIR−, ENA− | GND интерфейса |
| A+ / A− | Первая обмотка NEMA17 |
| B+ / B− | Вторая обмотка NEMA17 |
| +VDC / GND | Силовое питание по паспорту драйвера |

У Leadshine DM556 V3 питание 20–50 В постоянного тока, типично 24 В. Прежние силовые 12 В A4988 для этой модели ниже допустимого диапазона. Выберите входной уровень 5 В, режим STEP/DIR и активный фронт PUL по инструкции своего экземпляра. В данной схеме HIGH на ENA отключает драйвер, LOW разрешает работу. На вход интерфейса ENA со стороны GPIO21 поставьте подтяжку 10 кОм к 3,3 В для отключения при сбросе ESP32.

Проверьте ток фазы по паспорту двигателя и таблице драйвера, учитывая Peak/RMS. У DM556 нет настройки VREF от A4988. Число импульсов на оборот задаётся переключателями микрошагов драйвера. Обороты в минуту = 60 × частота STEP / импульсы на оборот. При 60 импульсах/с и 400 импульсах/оборот скорость составляет 9 об/мин. Для присланного DM556 выберите 400 импульсов/оборот: SW5=OFF, SW6=ON, SW7=ON, SW8=ON. В таблице тока этого экземпляра указан Peak. Для 17HS4401 с паспортным током 1,7 А/фазу настройка 2,1 А Peak (примерно 1,5 А RMS) задаётся SW1=OFF, SW2=ON, SW3=ON. Проверьте паспорт своего двигателя перед подачей питания.

Прошивка выдаёт STEP длительностью 5 мкс, устанавливает DIR за 10 мкс до STEP и выдерживает 300 мс после ENA. Подключайте обмотки при снятом питании. См. [руководство Leadshine DM556 V3](https://www.omc-stepperonline.com/download/DM556_User_Manual.pdf).

По умолчанию `ENABLE_STEPPER_POWER = 1`. Для проверки без выдачи шагов установите `0`.

Файл `docs/esp32-pinout.docx` описывает предыдущую схему с A4988. Для DM556 используйте подключение из этого раздела.

Актуатор активен: `#define ENABLE_ACTUATOR_POWER 1`. Для проверки без движения поставьте `0`.

## Сборка в PlatformIO

1. Откройте папку проекта в VS Code с PlatformIO.
2. Проверьте `platformio.ini` (`board=esp32dev`, `framework=arduino`).
3. Соберите Build и выполните Upload.
4. Serial Monitor 115200: проверяйте `STEPPER DM556: command / speed / power`, `CH2`, `CH3`, `DAC` и `relay`.
5. Первый тест ЦАП — с мультиметром и отключённой внешней нагрузкой. Реальный выход DAC ≈ 0…3,3 В, он не предназначен для прямого питания привода; амплитуда зависит от питания и нагрузки.
6. Сначала проверяйте CH2 на свободном ходе при готовой аварийной остановке. Не использовать без защиты механики.

## Остановка шаговика

В зоне стопа, при недопустимой команде или потере сигнала CH1 выдача STEP прекращается, ENA устанавливается в HIGH, ток обмоток отключается. Без тока удержания вал может провернуться от внешней нагрузки. Прошивка управляет направлением и частотой импульсов без измерения положения.


## Arduino Uno для CH1

Для управления DM556 от 5-вольтовых выходов Arduino Uno R3 используйте отдельный [скетч и распиновку](arduino_uno_ch1/README.md). Прошивка ESP32 сохраняет все свои каналы. Входы одного DM556 подключайте к одному контроллеру.
