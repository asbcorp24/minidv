# ESP32 DevKit: три RC-канала, относительный ноль шаговика

## Принцип работы

- **CH1 → HW-095 / NEMA17 17HS4401**: теперь управление **положением**, а не скоростью. 1000 мкс → 0°, 1250 → 90°, 1500 → 180°, 1750 → 270°, 2000 → 360° (200 полных шагов). Значения за пределами 1000–2000 ограничиваются ближайшим краем: 900 → 0°, 2400 → 360°.
- При включении питания **текущее положение ротора принимается за относительный 0°**, без концевика, энкодера и команды `Z`. Если ручка перед включением уже стояла на 2000 мкс, мотор после появления сигнала попытается выполнить **200 шагов (целый оборот)** от текущего места. При 1500 мкс — 100 шагов (пол-оборота). Выставление ручки предварительно **не блокирует движение**. Используйте только при свободном безопасном ходе!
- Угол рассчитывается по выданным шагам. Без датчика ESP32 **не может узнать фактический абсолютный угол, пропуск шагов или механическое перемещение вала при выключении**. 0° и 360° физически совпадают, но имеют разные счётчики шагов. При пропадании CH1 мотор выключается; при восстановлении входа текущее положение снова **принимается** за относительный ноль (предположение, не измерение).
- **CH2 → HW-039 / актуатор 12 В, два провода**: 900–1449 мкс одна сторона; 1450–1550 стоп; 1551–2400 другая сторона. Плавный разгон/реверс. Непрерывная команда движения прекращается через **10 секунд**, сброс таймера только после возврата в нейтраль. После потери радиосигнала требуется нейтраль для повторного включения.
- **CH3 → DAC1 GPIO25 + реле GPIO13**: `<=1440` — реле включено и ЦАП от 0 до максимума к 900 мкс; `1441..1549` — 0 В; `>=1550` — реле выключено и ЦАП возрастает до максимума при 2400 мкс. При реверсе сначала плавное снижение ЦАП до нуля, пауза 150 мс для переключения реле, затем плавный рост.

## Пины ESP32

| Функция | ESP32 | Подключить |
| --- | --- | --- |
| CH1 RC PWM | GPIO27 | сигнал приёмника CH1 |
| CH2 RC PWM | GPIO34 | сигнал приёмника CH2 |
| CH3 RC PWM | GPIO35 | сигнал приёмника CH3 |
| HW-095 | GPIO16,17,18,19 | IN1,IN2,IN3,IN4 |
| HW-095 ENA / ENB | GPIO21 / GPIO26 | снять перемычки ENA и ENB |
| HW-039 RPWM / LPWM | GPIO32 / GPIO33 | RPWM / LPWM |
| HW-039 R_EN / L_EN | GPIO23 / GPIO22 | R_EN / L_EN |
| HW-039 питание логики | отдельные 5 В | VCC и GND (общая земля) |
| ЦАП | GPIO25 | аналоговый высокоомный вход, **не питание нагрузки** |
| Реле | GPIO13 | управляющий вход модуля реле, **не катушка напрямую** |

Двигатель: две обмотки NEMA17 подключаются к OUT1/OUT2 и OUT3/OUT4 HW-095. Перед подключением проверить пары мультиметром. Актуатор подключается двумя проводами к M+/M− HW-039. Силовое питание актуатора 12 В — к B+/B− HW-039. Силовое питание шаговика — отдельное, рассчитанное по измеренному току фаз; нельзя просто подавать 12 В на HW-095 с низкоомным 17HS4401.

Сигнал RC с уровнем 5 В **нельзя** подавать прямо на ESP32: используйте делитель 1 кОм от выхода приёмника к GPIO и 2 кОм от GPIO к GND на каждом RC-канале, если выход приёмника 5 В. GPIO34/35 не имеют внутренних подтяжек. **Общая земля обязательна.** Питать ESP32 от USB, логическую часть HW-095 — от стабильных 5 В с учётом перемычки 5V-EN конкретного модуля; HW-039 — от 5 В логики. Для некоторых релейных модулей нужен транзисторный ключ или согласование уровней. Поставьте физические концевики и защиту тока актуатора: программный таймер не защищает от упора раньше 10 секунд.

## Безопасность HW-095

**Важное ограничение: HW-095 (L298N) НЕ ограничивает ток фаз двигателя 17HS4401 (~1.7 А/фаза, ~1.5 Ом).** Источник питания, регулирующий *только напряжение*, не заменяет драйвер с ограничением тока. Поэтому в `src/main.cpp` по умолчанию:

```cpp
#define ENABLE_STEPPER_POWER 0
```

В этом режиме CH1 измеряется и цель вычисляется для диагностики, но **NEMA17 не движется**, что правильно и безопасно до появления измеряемого ограничения тока. Переключение на `1` разрешается только после аппаратного обеспечения безопасного тока фаз и проверки обмоток/питания. Шаговик с выключенными обмотками не удерживает положение.

Актуатор активен: `#define ENABLE_ACTUATOR_POWER 1`. Для проверки без движения поставьте `0`.

## Сборка в PlatformIO

1. Откройте папку проекта в VS Code с PlatformIO.
2. Проверьте `platformio.ini` (`board=esp32dev`, `framework=arduino`).
3. Соберите Build и выполните Upload.
4. Serial Monitor 115200: проверяйте `CH1 position`, `CH2`, `CH3`, `DAC` и `relay`.
5. Первый тест ЦАП — с мультиметром и отключённой внешней нагрузкой. Реальный выход DAC ≈ 0…3,3 В, он не предназначен для прямого питания привода; амплитуда зависит от питания и нагрузки.
6. Сначала проверяйте CH2 на свободном ходе при готовой аварийной остановке. Не использовать без защиты механики.

## Ограничения

- Без энкодера/концевика **абсолютная ориентация после перезапуска неизвестна**. Фраза «текущее положение = 0» — условное назначение координаты, а не замер угла.
- При пропуске шагов, сдвиге вала рукой или отсутствии питания фаз вычисленный угол не соответствует реальному.
- 200 шагов = 360° для 1.8°/шаг, без учёта передаточных механизмов.
- При включении CH1 в ненулевом положении возможен немедленный поворот на соответствующий угол. Перед первым включением убедитесь, что такой поворот механически допустим.


## Отключение обмоток шаговика в целевой точке

После завершения поворота ESP32 устанавливает ENA=LOW и ENB=LOW, прекращая ток через обе обмотки HW-095. Параметр `STEPPER_RELEASE_WHEN_IDLE = true` в `src/main.cpp` включает данное поведение. При новой команде позиционирования мосты включаются повторно. При потере сигнала CH1 они также отключаются.

**Ограничение:** без тока удержания вал может провернуться от внешней нагрузки. ESP32 продолжит считать последнее расчётное положение верным, поскольку датчика угла нет. Также обесточивание после остановки не ограничивает ток *во время* движения; `ENABLE_STEPPER_POWER = 0` оставлен по умолчанию. Не включайте силовую часть до решения вопроса тока обмоток.
