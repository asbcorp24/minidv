# ESP32 DevKit: три RC-канала, относительный ноль шаговика

## Принцип работы

- **CH1 → A4988 / NEMA17 17HS4401**: теперь управление **положением**, а не скоростью. 1000 мкс → 0°, 1250 → 90°, 1500 → 180°, 1750 → 270°, 2000 → 360° (200 полных шагов). Значения за пределами 1000–2000 ограничиваются ближайшим краем: 900 → 0°, 2400 → 360°.
- При включении питания **текущее положение ротора принимается за относительный 0°**, без концевика, энкодера и команды `Z`. Если ручка перед включением уже стояла на 2000 мкс, мотор после появления сигнала попытается выполнить **200 шагов (целый оборот)** от текущего места. При 1500 мкс — 100 шагов (пол-оборота). Выставление ручки предварительно **не блокирует движение**. Используйте только при свободном безопасном ходе!
- Угол рассчитывается по выданным шагам. Без датчика ESP32 **не может узнать фактический абсолютный угол, пропуск шагов или механическое перемещение вала при выключении**. 0° и 360° физически совпадают, но имеют разные счётчики шагов. При пропадании CH1 мотор выключается; при восстановлении входа текущее положение снова **принимается** за относительный ноль (предположение, не измерение).
- **CH2 → HW-039 / актуатор 12 В, два провода**: 1000–1449 мкс одна сторона; 1450–1550 стоп; 1551–2000 другая сторона. Полный ШИМ достигается при 1000 и 2000 мкс. Принятые импульсы ниже 1000 ограничиваются до 1000, выше 2000 — до 2000. Импульсы вне диапазона захвата 800–2500 мкс отвергаются и не обновляют таймер наличия сигнала. Плавный разгон/реверс. Непрерывная команда движения прекращается через **10 секунд**, сброс таймера только после возврата в нейтраль. После потери радиосигнала требуется нейтраль для повторного включения.
- **CH3 → DAC1 GPIO25 + реле GPIO13**: `<=1440` — реле включено и ЦАП от 0 до максимума к 900 мкс; `1441..1549` — 0 В; `>=1550` — реле выключено и ЦАП возрастает до максимума при 2400 мкс. При реверсе сначала плавное снижение ЦАП до нуля, пауза 150 мс для переключения реле, затем плавный рост.

## Пины ESP32

| Функция | ESP32 | Подключить |
| --- | --- | --- |
| CH1 RC PWM | GPIO27 | сигнал приёмника CH1 |
| CH2 RC PWM | GPIO34 | сигнал приёмника CH2 |
| CH3 RC PWM | GPIO35 | сигнал приёмника CH3 |
| A4988 STEP / DIR / EN | GPIO16 / GPIO17 / GPIO21 | EN активен низким уровнем, подтяжка 10 кОм к VDD |
| HW-039 RPWM / LPWM | GPIO32 / GPIO33 | RPWM / LPWM |
| HW-039 R_EN / L_EN | GPIO23 / GPIO22 | R_EN / L_EN |
| HW-039 питание логики | отдельные 5 В | VCC и GND (общая земля) |
| ЦАП | GPIO25 | аналоговый высокоомный вход, **не питание нагрузки** |
| Реле | GPIO13 | управляющий вход модуля реле, **не катушка напрямую** |

Актуатор подключается двумя проводами к M+/M− HW-039. Силовое питание актуатора 12 В подключается к B+/B− HW-039.

Сигнал RC с уровнем 5 В **нельзя** подавать прямо на ESP32: используйте делитель 1 кОм от выхода приёмника к GPIO и 2 кОм от GPIO к GND на каждом RC-канале, если выход приёмника 5 В. GPIO34/35 не имеют внутренних подтяжек. **Общая земля обязательна.** Питать ESP32 от USB, логику HW-039 — от 5 В. Для некоторых релейных модулей нужен транзисторный ключ или согласование уровней. Поставьте физические концевики и защиту тока актуатора: программный таймер не защищает от упора раньше 10 секунд.

## Подключение A4988

| Контакт | Подключение |
| --- | --- |
| VDD | 3,3 В ESP32 |
| VMOT | +12 В силового питания |
| GND (оба) | Общий минус силового питания и ESP32 |
| RESET и SLEEP | Соединить с VDD |
| MS1, MS2, MS3 | GND для полного шага |
| 1A / 1B | Первая обмотка NEMA17 |
| 2A / 2B | Вторая обмотка NEMA17 |

Определите пары обмоток мультиметром. Установите электролитический конденсатор не менее 47 мкФ между VMOT и GND рядом с драйвером. Подключайте и отключайте двигатель при снятом питании.

Перед запуском установите ограничение тока по формуле VREF = 8 × Rs × Imax. Rs — сопротивление токовых шунтов конкретной платы. Imax выбирайте с учётом допустимого тока двигателя, платы и охлаждения. См. [даташит A4988](https://www.allegromicro.com/-/media/files/datasheets/a4988-datasheet.pdf) и [инструкцию Pololu](https://www.pololu.com/product/1182).

По умолчанию `ENABLE_STEPPER_POWER = 1`. Для проверки входного сигнала без движения установите `0`.

Актуатор активен: `#define ENABLE_ACTUATOR_POWER 1`. Для проверки без движения поставьте `0`.

## Сборка в PlatformIO

1. Откройте папку проекта в VS Code с PlatformIO.
2. Проверьте `platformio.ini` (`board=esp32dev`, `framework=arduino`).
3. Соберите Build и выполните Upload.
4. Serial Monitor 115200: проверяйте `CH1 position`, `CH2`, `CH3`, `DAC` и `relay`.
5. Первый тест ЦАП — с мультиметром и отключённой внешней нагрузкой. Реальный выход DAC ≈ 0…3,3 В, он не предназначен для прямого питания привода; амплитуда зависит от питания и нагрузки.
6. Сначала проверяйте CH2 на свободном ходе при готовой аварийной остановке. Не использовать без защиты механики.

## Ограничения

- Без энкодера/концевика **абсолютная ориентация после перезапуска неизвестна**. Фраза «текущее положение = 0» — условное назначение координаты, а не замер угла.
- При пропуске шагов, сдвиге вала рукой или отсутствии питания фаз вычисленный угол не соответствует реальному.
- 200 шагов = 360° для 1.8°/шаг, без учёта передаточных механизмов.
- При включении CH1 в ненулевом положении возможен немедленный поворот на соответствующий угол. Перед первым включением убедитесь, что такой поворот механически допустим.


## Отключение обмоток шаговика в целевой точке

При `STEPPER_RELEASE_IDLE = true` ESP32 поднимает EN до HIGH после достижения цели и отключает ток обмоток. При новой команде EN снова становится LOW. При потере сигнала CH1 драйвер отключается.

Без тока удержания вал может провернуться от внешней нагрузки. ESP32 продолжит использовать последнее расчётное положение, поскольку датчика угла нет.
